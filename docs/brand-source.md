# Wordmark source

Official website: https://www.branvidia.com/
Original raster wordmark: https://www.branvidia.com/branvidia-wordmark.png

The supplied SVG is a vector trace of that exact 921×155 transparent PNG, preserving its lowercase letterforms and original violet #4F18B4. It is not an original vector master supplied by the brand. The companion dark SVG changes the black letterforms to #F4F3F8 for legibility; violet stays unchanged. The app accent remains #5B21B6 in light mode.
