# Version 2 polish plan

Keep the product as the hero: a contained conversation beside a short business-growth promise. Preserve the accepted Inter body and Poppins headings rather than redesigning the app.

Palette: Paper #FAFAFC, Surface #FFFFFF, Ink #16151D, Slate #6B6880, Violet #5B21B6, Mist #F3EFFB. Dark mode uses the existing separately tuned tokens.

Desktop: left-aligned headline, explanation, sample-report button and privacy line; right-aligned chat with a fixed composer and its own message scroll. Mobile: chat first so typing is possible immediately, then the hero and privacy line below. Header remains 64px; chat maximum is viewport minus header minus 32px. Limit the first mobile chat to this same usable window.

Review: avoid a new decorative card system or new fonts. The conversation is the single focal element. Replace the generic monogram with a vector trace of the actual website wordmark; do not typeset a guessed logo. Preserve all sample-data notices.
